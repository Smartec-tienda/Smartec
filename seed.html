🌱 Migración inicial del sistema

Esta operación creará la estructura base para el sistema multi-tienda. Es segura de re-ejecutar: si algo ya existe, no lo duplica.

Se ejecutará en este orden:

  1. Actualizar tu usuario con campos nuevos (name, email, active)
  2. Crear Tienda Alameda (tienda-alameda)
  3. Crear Tienda Mallorquín (tienda-mallorquin)
  4. Crear settings/general (config global + categorías + estacionalidad)
  5. Migrar los productos existentes a la nueva estructura (variantes)
  6. Crear inventario por tienda para cada variante
  7. Registrar todo en auditLog
